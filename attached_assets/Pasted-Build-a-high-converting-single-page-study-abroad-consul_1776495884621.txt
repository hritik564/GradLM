Build a high-converting, single-page study abroad consultancy website using React + Tailwind CSS. The design should be premium, modern, and inspired by GradRight.com — clean whitespace, bold typography, vibrant gradient accents (deep blue to violet), subtle animations, and strong trust signals. The site must be fully mobile-responsive.

---

## BRAND & DESIGN SYSTEM

- Primary color: #2D31FA (electric blue)
- Accent gradient: linear-gradient(135deg, #2D31FA, #7B2FBE)
- Background: #FFFFFF with soft #F4F6FF section breaks
- Font: Inter (Google Fonts) — bold headings, regular body
- Rounded corners: 16px cards, 999px buttons
- Micro-animations: fade-in-up on scroll (use Intersection Observer), counter animation on stats, hover lift on cards (translateY -4px, box-shadow)
- NO stock photo placeholders — use abstract SVG illustrations or gradient blobs

## TECHNICAL REQUIREMENTS

- React functional components only
- Tailwind CSS for all styling (CDN via script tag in index.html or via Vite config)
- Intersection Observer API for scroll animations (no GSAP, no AOS library)
- All animations in pure CSS keyframes or Tailwind transition classes
- Form state managed with useState (multi-step)
- Modal (lead form) triggered by nav CTA button — built with React portal or conditional render + backdrop
- No external UI library (no shadcn, no MUI, no Chakra)
- No image imports — all visuals are SVG or CSS gradient shapes
- Mobile-first responsive: 1-column on mobile, 2-3 columns on tablet/desktop
- Smooth scroll on nav link clicks
- Page load: all above-fold content renders in <1s (no heavy imports)
